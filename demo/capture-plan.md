# Capture Plan: Staged Engagement Party

This plan makes the real photo set for the finalist test day. It is a staged party at home, of about 2.5 hours, with about 300 frames. The shot list is `shot-list/rivera-okoro-shot-list.pdf`.

Do the shoot before Nov 21, so that the photos are ready for the assigned test day (Nov 22 to 28).

## People

| Role on the shot list | Who plays it | Name in the photo app |
|---|---|---|
| Ana | friend 1 | Ana Rivera |
| Daniel | friend 2 | Daniel Okoro |
| Grandma Rosa | an older friend or relative | Rosa Rivera |
| Maya, best friend | friend 3 | Maya Chen |
| Guests | 4 to 8 more friends | no names |

Everyone must agree to the photos, and to their use in a public demo video. Do not invite children: shot 14 is a planned miss.

## Props

Print `shot-list/props-to-print.pdf`:

- Page 1: the welcome sign for shot 3.
- Page 2: the cake topper "A & D" for shot 11. Tape it to two skewers.
- Page 3: the "Table 4" place cards for shot 15.

Also bring: a ring, flowers, a cake, glasses for the toast, and string lights.

Do not make menu cards. Shot 16 is a planned miss.

## Camera

- Set the camera clock to the correct local time. The Skill uses capture times for the time windows.
- Shoot JPEG. If your camera shoots RAW, use RAW + JPEG to also test RAW previews.
- Use one camera, so that the file names are in one sequence.

## After the shoot

1. Copy all frames to one folder, for example `Photos/2026-11 Rivera-Okoro party`.
2. Keep a copy of the full set off the NAS. The test NAS is a remote machine for one day.
3. Write down the first eyes-open frame of shot 10. The edge run needs it.
