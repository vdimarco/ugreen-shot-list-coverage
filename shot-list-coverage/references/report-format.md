# Report format

Use this layout in the conversation and in the saved report file. Use the real event name, counts, and file paths.

```markdown
# Rivera wedding: shot list coverage

Checked: 2026-11-24 21:40
Shoot folder: Photos/2026-11-24 Rivera wedding (1,284 images)
Shot list: Documents/Clients/Rivera/shot-list.pdf (42 shots, 12 must-have)

## Missing must-have shots
- 17. Bride with grandmother (must-have): missing. No photo shows both people.
- 31. Rings on the bouquet (must-have): weak. Out of focus in all 2 matches.

## Summary
| Status | Shots |
|---|---|
| Covered | 36 |
| Weak | 3 |
| Missing | 2 |
| Not checked | 1 |

## All shots
| # | Shot | Must | Status | Best frame | Alternates | Notes |
|---|---|---|---|---|---|---|
| 1 | Dress on the hanger | | covered | IMG_0012.CR3 | IMG_0013.CR3, IMG_0019.CR3 | |
| 17 | Bride with grandmother | yes | missing | | | No photo shows both people. |
| 31 | Rings on the bouquet | yes | weak | IMG_0718.CR3 | IMG_0719.CR3 | Out of focus in all 2 matches. |
```

Rules:

- "Missing must-have shots" lists every must-have shot with the status weak, missing, or not checked. If there are none, write "None. All must-have shots are covered."
- In the table, show file names only. The saved report file gives the folder once, at the top.
- Keep the shots in the order of the shot list.
- Write "Not checked" shots with the reason, for example "Run limit of 150 photos" or "Search failed".
