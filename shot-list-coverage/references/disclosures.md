# Disclosures

## Third-party components and open source libraries

None. This Skill contains only Markdown instructions. It uses no third-party library, service, model, or download. All NAS work goes to the registered UGOS experts named in SKILL.md.

## Tools used to make this Skill

- UGREEN uliya-skill-kit 0.7.3, from the UGREEN Hackathon Starter Kit. It was used to check the capability catalog and to run the static check. The kit is not part of this package.

## Work done for the Hackathon

All files in this package were written during the UGREEN Hackathon 2026 on AI NAS. The principal functions made for the Hackathon are:

- The shot list workflow: read the shot list, find candidates by scene, person, object, text, and time, check them with the vision model, and report each shot.
- The coverage rules: the statuses covered, weak, missing, and not checked, the choice of the best frame, and the run limits.
- The report format, the album of best frames, and the saved report.

## AI tools used

- Claude (Anthropic): used to research the Hackathon rules and the capability catalog, to draft and edit SKILL.md and the reference files, and to review the files against the static check results. The entrant reviewed and approved all content.
